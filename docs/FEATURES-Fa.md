# فهرست کامل امکانات / Full feature list

> The plugin UI is Persian; this list is in Persian too. Total features: **161** (v2.1.0). A short English summary per category is in the main README.

## سمت بازدیدکننده

کدها و فایل‌های اضافه‌ای که وردپرس در صفحات سایت می‌گذارد را حذف کنید.

### سربرگ صفحه

| امکان | توضیح | نکته |
|---|---|---|
| حذف اسکریپت و استایل ایموجی | مرورگرهای امروزی ایموجی را خودشان نمایش می‌دهند. با این گزینه فایل‌های اضافه‌ای که وردپرس برای ایموجی در هر صفحه بارگذاری می‌کند حذف می‌شود. | پیشنهادی |
| حذف برچسب RSD | این برچسب فقط برای برنامه‌های قدیمیِ نوشتن از راه دور لازم بود. اگر با چنین برنامه‌ای مطلب منتشر نمی‌کنید، حذفش امن است. | پیشنهادی |
| حذف WLW Manifest | فایلی مربوط به نرم‌افزار قدیمی Windows Live Writer که سال‌هاست پشتیبانی نمی‌شود. حذفش به ظاهر و کارکرد سایت آسیبی نمی‌زند. | پیشنهادی |
| حذف لینک کوتاه (Shortlink) | وردپرس برای هر نوشته یک آدرس کوتاه شبیه ?p=123 در کد صفحه می‌گذارد. اگر از آن استفاده نمی‌کنید حذفش کنید. |  |
| پنهان‌کردن نسخه‌ی وردپرس | نسخه‌ی وردپرس در کد سایت نوشته می‌شود و به هکرها کمک می‌کند ضعف‌های همان نسخه را پیدا کنند. با این گزینه پنهان می‌شود. | پیشنهادی |
| حذف لینک نوشته‌ی قبلی و بعدی | برچسب‌هایی که نوشته‌ی قبلی و بعدی را به موتورهای جستجو معرفی می‌کردند. امروز تقریباً اثری ندارند. |  |
| حذف پیش‌اتصال دامنه‌ها (DNS Prefetch) | وردپرس به مرورگر می‌گوید زودتر به دامنه‌های خارجی وصل شود. حذفش کد را سبک‌تر می‌کند، اما ممکن است بارگذاری فایل‌های خارجی کمی دیرتر شروع شود. | نیازمند بررسی |
| آیکن خالی برای سایت‌های بدون favicon | اگر برای سایت آیکن (favicon) نگذاشته‌اید، مرورگرها یک درخواست اضافه می‌فرستند و خطای ۴۰۴ می‌گیرند. این گزینه یک آیکن خالی معرفی می‌کند. اگر برای سایت آیکن تعیین کرده باشید اثری ندارد. |  |
| حذف لینک REST API از سربرگ | برچسب و سرایندی که REST API را معرفی می‌کند از صفحه حذف می‌شود. خود REST API همچنان کار می‌کند. | پیشنهادی |

## مسدودسازی دامنه‌ها

درخواست‌های سایت و مرورگر به دامنه‌های فیلتر یا کندکننده را قطع کنید یا فقط دامنه‌های مجاز را باز بگذارید.

### حالت و فهرست‌ها

| امکان | توضیح | نکته |
|---|---|---|
| حالت کنترل درخواست‌ها | در «فهرست سیاه» فقط دامنه‌های فهرست مسدود می‌شوند. در «فهرست سفید» همه‌چیز به‌جز دامنه‌های فهرست سفید مسدود است (مناسب قطعی اینترنت بین‌الملل). درخواست‌ها به خود سایت هرگز مسدود نمی‌شود. | نیازمند بررسی، انتخابی |
| فهرست سیاه دامنه‌ها | هر دامنه در یک خط. زیردامنه‌ها هم شامل می‌شوند. با دکمه‌های افزودن سریع یا نتیجه‌ی اسکن سایت می‌توانید فهرست را پر کنید. |  |
| فهرست سفید دامنه‌ها | در حالت فهرست سفید فقط این دامنه‌ها مجاز هستند. هر دامنه در یک خط. |  |
| یادگیری خودکار دامنه‌های خارجی | افزونه هنگام بازدیدهای عادی از صفحه‌های سایت (و پیشخوان) گاهی‌گاهی دامنه‌های خارجی را شناسایی و در «پیشنهادها» ذخیره می‌کند. نیازی به اسکن دستی نیست و فشاری به سرور نمی‌آورد، چون فقط از بخش کوچکی از بازدیدها نمونه می‌گیرد. | پیشنهادی |
| پیشنهادهای دامنه | دامنه‌های خارجی که به‌صورت خودکار پیدا شده‌اند، به ترتیب تعداد دفعات. هر کدام را که خواستید با یک کلیک به فهرست سیاه اضافه کنید. |  |

## مخفی‌سازی منوها

منوها و زیرمنوهای پیشخوان و نوار بالا را پنهان کنید؛ فهرست با نصب افزونه‌های جدید خودکار به‌روز می‌شود.

### منوی کناری پیشخوان

| امکان | توضیح | نکته |
|---|---|---|
| منوها و زیرمنوهایی که مخفی شوند | تیک بزنید تا منو یا زیرمنو پنهان شود. افزونه‌ی تازه‌نصب‌شده خودکار در همین فهرست پیدا می‌شود. توجه: پنهان‌کردن فقط منو را برمی‌دارد و دسترسی با آدرس مستقیم بسته نمی‌شود. |  |
