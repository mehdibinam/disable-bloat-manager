## 🇮🇷 فارسی

### معرفی
Bloat Manager یک افزونه سبک و یکپارچه است که قابلیت‌های چندین افزونه محبوب بهینه‌سازی (Perfmatters، Disable Admin Notices، Featherweight، Disable Bloat for WP & Woo و ...) را در یک رابط مدرن با تب‌های AJAX و تولتیپ ارائه می‌دهد. بیش از ۱۰۰ گزینه برای کاهش درخواست‌ها، حجم صفحه و شلوغی پنل مدیریت.

### نصب
1. پوشه افزونه را با نام `bloat-manager` در مسیر `wp-content/plugins/` قرار دهید.
2. افزونه را از بخش «افزونه‌ها» فعال کنید.
3. به **تنظیمات ← Bloat Manager** بروید و گزینه‌های دلخواه را روشن کنید.

### راهنمای استفاده
- همه گزینه‌ها به‌صورت پیش‌فرض **خاموش** هستند و هیچ تغییری اعمال نمی‌شود تا خودتان فعال کنید.
- گزینه‌های دارای نشان «⭐ مهم» بیشترین تاثیر را بر سرعت دارند.
- نشانگر «؟» کنار هر گزینه توضیح کامل را نمایش می‌دهد.
- گزینه‌های ووکامرس و افزونه‌های جانبی فقط در صورت فعال بودن افزونه مربوطه اعمال می‌شوند.
- پس از فعال‌سازی گزینه‌های حساس (REST API، XML-RPC، فید، کامنت) سایت را تست کنید.

## 🇬🇧 English

### About
Bloat Manager is a lightweight, unified plugin that brings the features of several popular optimization plugins (Perfmatters, Disable Admin Notices, Featherweight, Disable Bloat for WP & Woo, and more) into one modern interface with AJAX tabs and tooltips. It offers 100+ options to cut requests, page weight, and admin clutter.

### Features

| Category | Highlights |
|---|---|
| **Frontend & Core** | Remove emojis, Embed/oEmbed, Dashicons, jQuery Migrate, `?ver=` query strings, Block Library & Global Styles CSS, DNS prefetch, shortlink, RSD, WLW, generator tag, RSS feeds, self-pingbacks, password strength meter, comments, core sitemaps, command palette |
| **Admin & Dashboard** | Clean dashboard, remove help tabs & Screen Options, Site Health, import/export, Heartbeat control, revisions limit, Autosave interval, login page tweaks, smart detection for admin bar items & sidebar widgets |
| **WooCommerce** | Disable Analytics & Marketing, marketplace suggestions, Cart Fragments, scripts/styles on non-shop pages, block styles, widgets, email promos, shipping suggestions |
| **Block Editor** | Revert to classic editor, disable Welcome Guide, Block Directory, default & remote patterns, template editor |
| **Third-party** | Jetpack nags/Blaze, Elementor widget & Google Fonts, Yoast promos & HTML comment, Contact Form 7 assets, ACF menu, UpdraftPlus |
| **AI** | Disable AI in WordPress core, Elementor, Rank Math, Yoast, Jetpack, and Bertha |
| **Privacy & Security** | XML-RPC, REST API for guests, user enumeration, author archives, file editor, application passwords, auto-updates, 7-day trash |
| **Misc** | Remove plugin suggestions & popular tags, per-notice admin notice control (hide / hide forever / compact panel) |

### Installation
1. Place the plugin folder as `bloat-manager` inside `wp-content/plugins/`.
2. Activate it from the **Plugins** screen.
3. Go to **Settings → Bloat Manager** and enable the options you want.

### Usage Guide
- Every option is **off by default**; nothing changes until you turn it on.
- Options tagged "⭐ Important" have the biggest performance impact.
- Hover the "?" icon beside an option for a detailed explanation.
- WooCommerce and third-party options only apply when the related plugin is active.
- Test your site after enabling sensitive options (REST API, XML-RPC, feeds, comments).
