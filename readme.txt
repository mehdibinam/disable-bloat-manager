مدیریت کارایی وردپرس — مجموعه دستهبندیشده برای خاموشکردن بخشهای اضافه وردپرس، ووکامرس و افزونهها، همراه با امنیت و کنترل دامنههای بیرونی.

== Description ==

**مدیریت کارایی وردپرس** (WordPress Performance Manager) یک جعبهابزار RTL و کاملاً فارسی با ۱۶۱ امکان است که قابلیتهای چندین افزونه بهینهسازی محبوب (Perfmatters، Disable Admin Notices، Featherweight، Disable Bloat for WP & Woo و ...) را در یک رابط مدرن گردآوری کرده است.

امکانات اصلی نسخه ۲٫۱:

* **جستجو و مدیریت سریع:** جستجوی امکانات (کلید `/`)، دکمهی فعال/غیرفعالکردن همه در هر بخش، حالت تیره/روشن، تنظیمات پیشنهادی و بازنشانی.
* **هشدار تداخل:** تشخیص همپوشانی با افزونههایی مانند Perfmatters، WP Rocket، Wordfence و Disable Bloat.
* **امنیت و فایروال:** سختسازی وردپرس، هدرهای امنیتی و HSTS، محافظت از ورود، آدرس سفارشی صفحه ورود، بررسی الگوهای حمله، بارگذاری فایلها، اسکنرها، متدها و نرخ درخواست.
* **مسدودسازی دامنهها:** فهرست سیاه/سفید، یادگیری خودکار دامنههای خارجی، حذف فایلهای خارجی، مسدودکردن fetch/XHR و قطع تله متری.
* **مخفیسازی منوها:** پنهان کردن منوها و موارد نوار بالا با تشخیص خودکار افزونههای جدید.
* **سایر بخشها:** سمت بازدیدکننده، دیدگاهها، پیشخوان، ویرایشگر بلوک، ابزارکها، بهروزرسانیها، ووکامرس، فونتهای گوگل و هوش مصنوعی.

ایدهٔ اولیهٔ این پروژه با الهام از افزونههای زیر شکل گرفت: bad domain blocker, bloatoff utils, disable admin notices, Disable Bloat for WP & Woo Pro, disable everything, Featherweight, ghateino (https://github.com/shokrino/ghateino), perfmatters, wp widget disable.

مزیت اصلی: فقط امکانهای انتخابی اجرا میشوند، تماسهای بیرونی کاهش مییابد، وابستگی به CDN کمتر میشود و عیبزدایی با تولتیپها و هشدارهای تداخل سادهتر است.

فهرست کامل امکانات: [فارسی](docs/FEATURES-Fa.md) · [English](docs/FEATURES-En.md).

تمام گزینهها بهصورت پیشفرض خاموشاند و دکمه «تنظیمات پیشنهادی» گزینههای ایمن را یکجا روشن میکند.

== Installation ==

1. آخرین نسخه را از [بخش Releases](https://github.com/mehdibinam/disable-bloat-manager/releases/latest) دانلود و از مسیر **افزونهها ← افزودن ← بارگذاری افزونه** آپلود یا پوشه `disable-bloat-manager` را در `wp-content/plugins/` قرار دهید.
2. افزونه را فعال کنید.
3. از منوی **مدیریت کارایی** وارد شوید و گزینههای دلخواه را روشن کنید.
4. قبل از استفاده روی سایت اصلی، روی سایت آزمایشی امتحان و پشتیبان تهیه کنید.
